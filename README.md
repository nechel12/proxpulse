# ProxPulse

Быстрый чекер прокси на Tauri + Rust. Черный хайтек с красными акцентами.

## Формат входа
Автоопределение, каждый с новой строки (а также CSV, JSON, логи):
- `127.0.0.1:8080`, `proxy.example.com:8080`, `[2001:db8::1]:8080`
- `user:pass@127.0.0.1:8080`
- `http://...`, `socks5://...`, `socks4://...` (регистр не важен)
- `127.0.0.1:8080:user:pass`, `user:pass:127.0.0.1:8080`
- `127.0.0.1:8080:socks5`, `127.0.0.1,8080,user,pass`
- JSON: `{"host":"...","port":8080,"username":"u","password":"p"}`

## Запуск
```sh
npm install
npm run tauri dev
```

## Сборка
```sh
npm run tauri build
```

## Проверки
- Пинг, джиттер и success rate (N замеров), тип без схемы HTTP+SOCKS5.
- Гео и тип IP (через ip-api, бесплатно ~45 запр/мин на IP выхода).
- Анонимность elite/anonymous/transparent (эвристика по заголовкам httpbin).
- Целостность трафика (сверка тела example.com с прямым соединением).

Ограничения: точный тип IP (резидентский vs бизнес) без платной ASN-базы
невозможен — показывается эвристика hosting/mobile + ISP/ORG/ASN.
