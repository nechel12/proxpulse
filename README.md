[![GitHub release](https://img.shields.io/github/v/release/nechel12/proxpulse)](https://github.com/nechel12/proxpulse/releases) [![Downloads](https://img.shields.io/github/downloads/nechel12/proxpulse/total)](https://github.com/nechel12/proxpulse/releases) [![Release build](https://github.com/nechel12/proxpulse/actions/workflows/release.yml/badge.svg)](https://github.com/nechel12/proxpulse/actions/workflows/release.yml) ![Windows](https://img.shields.io/badge/platform-Windows-0078D6?logo=windows&logoColor=white) [![License](https://img.shields.io/github/license/nechel12/proxpulse)](LICENSE)

*[English version](README_EN.md)*

Десктопный чекер прокси с живым интерфейсом: проверка живости, пинга,
гео, анонимности, целостности трафика и TLS — плюс локальный
прокси-диспетчер, автопроверки по таймеру и рассылка живых на вебхуки.

Стек: **Tauri 2 + Rust (tokio, reqwest, rustls) + Vite + TypeScript**.
Тёмная тема с красными акцентами, русский и английский язык.

> Готовая сборка для Windows — во вкладке [Releases](https://github.com/nechel12/proxpulse/releases):
> установщик (`-setup.exe` / `.msi`) и portable `.exe`. Установленная версия
> обновляется сама (вкладка «Инфо» → проверка обновлений), portable
> обновляется скачиванием нового файла вручную.

## Быстрый старт

Нужны [Node.js 18+](https://nodejs.org/), [Rust](https://rustup.rs/)
и WebView2 (в Windows 10/11 уже встроен).

```sh
npm install
npm run tauri dev     # запуск в dev-режиме
npm run tauri build   # сборка установщика
```

Проверки кода:

```sh
npm run build         # tsc + vite build
npm test              # vitest: парсинг прокси (фронт)
cargo test --manifest-path src-tauri/Cargo.toml --lib   # юнит-тесты (бэкенд)
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
```

## Проверка (вкладка «Проверка»)

Вставь список в поле слева (каждый с новой строки) и жми **Старт**.
Результаты появляются вживую, по мере готовности. Кнопка **Стоп**
реально прерывает проверку.

### Поддерживаемые форматы

Автоопределение, регистр схемы не важен:

- `127.0.0.1:8080`, `proxy.example.com:8080`, `[2001:db8::1]:8080`
- `user:pass@127.0.0.1:8080`
- `http://…`, `https://…`, `socks5://…`, `socks4://…`
- `127.0.0.1:8080:user:pass` и наоборот `user:pass:127.0.0.1:8080`
- `127.0.0.1:8080:socks5` (протокол суффиксом)
- CSV/табы/пробелы: `127.0.0.1,8080,user,pass`
- JSON: `{"host":"…","port":8080,"username":"u","password":"p"}`, массивы и логи
- Нумерованные списки (`1) …`, `- …`), комментарии `# …`

Дубликаты отсеиваются автоматически. Импорт из файла (txt, csv, json,
log — вообще любые текстовые) и по URL — список качается встроенным
клиентом (лимит 2 МБ) и парсится так же.

### Тестовые URL

- `google generate_204`, `cloudflare generate_204` — быстрые, без тела
- `api.ipify.org`, `httpbin.org/ip` — показывают IP выхода
- `ip-api.com/json` — сразу IP + гео
- `example.com` — обычная страница
- **ProxPulse Judge** — свой backend для проверок (см. ниже);
  поле рядом позволяет указать свой инстанс. Два режима:
  **Быстрая** (`/generate_204`) и **Полная** (`/judge` — гео, анонимность
  и тип IP приходят одним ответом, плюс сверка целостности по хешу контента)

Свой URL тоже можно вписать вручную.

### Настройки замера

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Таймаут, мс | 5000 | лимит одного HTTP-запроса (1000–30000) |
| Потоки | 50 | параллельных проверок (1–500) |
| Замеры | 1 | повторов на прокси для пинга/джиттера/SR (1–5) |
| Тип без схемы | HTTP | что подставлять, если схемы нет; режим HTTP + SOCKS5 проверяет оба |
| Пречек порта | вкл, 1500 мс | быстрый TCP-коннект: мёртвые отсеиваются до тяжёлой проверки |

Настройки сохраняются именованными **профилями** («Быстрый», «Глубокий»,
«Judge» из коробки + свои): выбор, сохранение и удаление — в один клик.

### Глубокие проверки (не для judge-режима)

- **Гео и тип IP** — через ip-api (страна/город/ISP/ORG/ASN, mobile/datacenter/residential)
- **Анонимность** — `elite` / `anonymous` / `transparent` (эвристика по заголовкам через httpbin + сверка со своим прямым IP)
- **Целостность** — сверка тела example.com с прямым соединением (`ok` / `modified`)
- **TLS-интегрити** — сверка SHA256 сертификата example.com (`ok` / `modified`)

Каждая глубокая проверка — это дополнительные запросы через прокси,
поэтому они отключаемые. В judge-режиме не нужны: judge отдаёт всё сам.

### Экспорт

Меню **Экспорт**: `.txt` (только прокси), `.json` (полные результаты),
`.csv` (таблица), **Скопировать**. Квадрат **«мёртвые»** рядом переключает,
включать ли мёртвые в экспорт. Сохранение — через системный диалог.

Под таблицей — спарклайн среднего пинга живых по проверкам (история
хранится локально).

## Диспетчер (вкладка «Диспетчер»)

Поднимает **локальный прокси на 127.0.0.1:порт** (по умолчанию 1080)
и гоняет трафик через живые из проверки. Один порт отвечает сразу
**HTTP и SOCKS5** (автоопределение по первому байту) либо только выбранный
протокол. Если порт занят — автоматически берётся следующий свободный
(+1, +2, …), фактический порт подставляется в поле и виден клиенту.

- Режимы: **ротация**, **самый быстрый**, **замена при падении**
- Пул пополняется слиянием (старые записи сохраняются); кнопки
  «Синхронизировать» / «Очистить»; фильтр и сортировка пула
  (по пингу / стране)
- **Макс. пинг**: прокси медленнее лимита в пул не попадают (`0` — без лимита)
- Счётчики запросов/ошибок, текущий апстрим, последняя ошибка
- Автопроверка пула каждые N минут с выкидыванием мёртвых

## Авто (вкладка «Авто»)

Тот же общий пул, отдельный таймер: перепроверка каждые N минут,
мёртвые вылетают. После каждой автопроверки пул уходит **POST-запросом
на вебхуки** (до 10 штук, общий формат txt/json/csv на выбор).
Кнопки «Проверить сейчас» и «Отправить сейчас» для ручного запуска.

## Инфо, трей, диагностика (вкладка «Инфо»)

- Ссылки на GitHub: сам чекер и ProxPulse Judge
- **Диагностика**: версия приложения, проверка обновлений (через
  GitHub Releases, установка с перезапуском), копирование отчёта
  (версия, счётчики, последние ошибки)
- Кнопка ⇲ в шапке сворачивает окно в трей. В трее (ПКМ): показать/скрыть,
  вкл/выкл диспетчера с текущим портом, время до следующих автопроверок,
  состояние вебхука, выход. Клик ЛКМ — показать/скрыть окно.

## Приватность и данные

Что уходит наружу при проверке: запросы к выбранному тестовому URL
(и к ip-api/httpbin/example.com при включённых глубоких проверках),
прямые запросы без прокси для baseline (свой IP, эталон example.com),
запросы к своему/публичному инстансу Judge, проверка релизов на GitHub,
POST на твои вебхуки, загрузка списка по URL. Пароли прокси передаются
только самим прокси в заголовках авторизации — больше никуда.

Локально в браузере хранится: язык, лимит пинга, вебхуки, geo-кэш
(до 2000 записей), последние ошибки, история пинга, профили настроек.
Лечится очисткой localStorage.
