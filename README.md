# ProxPulse

Быстрый чекер прокси на Tauri + Rust. Черный хайтек с красными акцентами.

## Формат входа
Каждый прокси с новой строки:
- `127.0.0.1:8080`
- `user:pass@127.0.0.1:8080`
- `http://127.0.0.1:8080`, `socks5://127.0.0.1:1080`, `socks4://...`
- `127.0.0.1:8080:user:pass`

## Запуск
```sh
npm install
npm run tauri dev
```

## Сборка
```sh
npm run tauri build
```

## Настройки
- Тестовый URL, таймаут, потоки, тип по умолчанию.
- Проверка прямого соединения, импорт из файла, экспорт живых в .txt.
